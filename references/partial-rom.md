# Partial ROM (only the cartridge files a room uses)

Goal: upload a 3 MB ROM instead of the full one (~56 MB of `nitrofiles`) to debug one room or mechanic.

One command:

```powershell
powershell -NonInteractive -ExecutionPolicy Bypass -File scripts\build-partial-rom.ps1 -ProjectPath <wt> -Variant <v> -Scenario <scenario.json> [-Verify] [-NoRecord]
```

1. `build-project.ps1 -Variant <v> -NitroTrace`: adds `NITRO_TRACE=1` and the link flags from `ldflags` (project.json root or `variants.<v>.ldflags`; the project uses `-Wl,--wrap=fopen -Wl,--wrap=open`). Own tree `<v>-trace`, ROM `<rom>-<v>-trace.nds`. Normal builds never get these flags.
2. The game (project side) wraps `fopen`/`open` and stores every `nitro:/` path in the global `g_nitro_trace` (`{u32 len; char data[12284]}`, NUL-separated, relative to `nitrofiles/`, no duplicates). The script copies the scenario, points `state.elf` at the trace ELF, appends a final `state_capture` that reads that symbol as 3072 `u32` fields, runs it and decodes it from `manifest.json`. No emulator-log parsing.
3. List saved to `<project>\.ds-game-dev\partial\<v>.txt` (union with the existing one, ordinal-sorted, one path per line, `#` comments allowed): versionable and hand-editable; rebuild after editing with `-NoRecord`. `soundbank.bin` is skipped (generated by the build); opened paths that are not in `nitrofiles/` are ignored with a message.
4. `build-project.ps1 -Variant <v> -NitroList <list>`: the `copy` item whose destination is `nitrofiles` only copies the listed files (fails with the missing names if any does not exist). Own tree `<v>-parcial`, ROM `<rom>-<v>-parcial.nds`.
5. Upload: `upload-rom.ps1 -ProjectPath <wt> -RomPath <rom>-<v>-parcial.nds -ConfirmUpload` (remote name stays `romUploadName`).

`-Verify` replays the scenario on the partial ROM and prints a contact sheet. Limits: only what the scenario touches is recorded (other rooms, bosses, menus not visited are missing: the game must tolerate a missing file, or add it to the list by hand); a direct hardware read that bypasses `fopen`/`open` is not seen.
